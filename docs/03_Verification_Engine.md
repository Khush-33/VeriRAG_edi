# Verification Engine

## Overview
The Verification Engine is the core research component of VeriRAG. Its purpose is to determine whether an atomic claim generated by the RAG system is actually supported by the source documents. 

To achieve this without relying on an expensive LLM-as-a-judge, VeriRAG employs a lightweight, local ML pipeline leveraging Hugging Face Transformers (`@xenova/transformers`).

## Methodology

The verification process is implemented in `src/server/verificationEngine.ts` and runs locally. It compares different approaches:

1. **Semantic Similarity (Extractor Pipeline)**
   - Uses `Xenova/all-MiniLM-L6-v2` to generate dense 384-dimensional embeddings for both the claim and the retrieved evidence chunks.
   - Computes Cosine Similarity between the vectors.
   - While fast, semantic similarity alone can be easily fooled by contradictory statements that share the same vocabulary (e.g., "is allowed" vs "is not allowed").

2. **Natural Language Inference (NLI Pipeline)**
   - Uses a Cross-Encoder model (`Xenova/nli-deberta-v3-small`).
   - NLI determines the logical relationship between the premise (evidence) and the hypothesis (claim).
   - Outputs probabilities for three classes:
     - **Entailment**: The evidence supports the claim.
     - **Contradiction**: The evidence directly conflicts with the claim.
     - **Neutral**: The evidence is insufficient to prove or disprove the claim.

3. **Hybrid Approach**
   - Combines Semantic Similarity and NLI to produce a robust verdict.
   - First, retrieves the top `K` most semantically similar evidence chunks.
   - Second, evaluates the entailment and contradiction probabilities using the NLI model.
   - Calculates an aggregated confidence score and assigns a final verdict (`SUPPORTED`, `UNSUPPORTED`, `CONTRADICTED`).

## Output
For each claim, the Verification Engine returns:
- **Verdict**: Is the claim supported, unsupported (hallucinated), or contradicted?
- **Confidence**: A percentage score representing the reliability of the verdict.
- **Evidence**: The specific text chunk and page number from the source document that was used for verification.
